## ✨ Introduction

The **AI Resume Analyzer** is a web application developed as part of a student academic project.  
It allows users to upload their resumes and automatically extract information such as:

- Skills  
- Experience  
- Education  
- Summary  

The system also generates an **ATS Score** and gives suggestions to improve the resume according to common Applicant Tracking System rules.

This project demonstrates skills in frontend development, resume parsing, AI integration, and clean UI design.

---

## ⚙️ Tech Stack

- **React** – Frontend UI framework  
- **React Router** – Navigation and routing  
- **Puter.js** – For simple auth, storage, and file handling  
- **Tailwind CSS** – Styling framework  
- **TypeScript** – Strongly typed JavaScript  
- **Vite** – Fast development server and bundler  
- **Zustand** – Lightweight state management  

---

## 🔋 Features

- **Resume Upload** – Upload PDF or text-based resumes  
- **Automatic Parsing** – Extracts skills, experience, and education  
- **AI-Based ATS Score** – Provides feedback and scoring based on resume content  
- **Modern Clean UI** – Fully responsive interface  
- **Real-time Suggestions** – Improves resume quality instantly  
- **Client-Side Processing** – Data handled securely in the browser
